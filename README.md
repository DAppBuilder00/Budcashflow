# 💰 BudgetFlow Pro

A modern **Budget & Cash Flow Calculator** built using **HTML, CSS, JavaScript, and Chart.js**. BudgetFlow Pro helps individuals and small businesses monitor income, expenses, savings, and cash flow through a clean fintech-inspired dashboard.

---

# Features

## 📊 Dashboard

* Real-time financial overview
* Total Income
* Total Expenses
* Remaining Balance
* Savings Rate
* Daily Budget
* Budget Health Indicator

---

## 💵 Budget Calculator

Calculate:

* Monthly Income
* Fixed Expenses
* Variable Expenses
* Savings Goal
* Total Expenses
* Remaining Budget
* Daily Budget
* Weekly Budget
* Monthly Budget
* Yearly Budget

---

## 💸 Cash Flow Calculator

Track:

* Opening Balance
* Cash In
* Cash Out
* Net Cash Flow
* Ending Balance

---

## 📈 Interactive Charts

Powered by Chart.js

* Doughnut Chart

  * Fixed Expenses
  * Variable Expenses
  * Remaining Budget

* Bar Chart

  * Cash In
  * Cash Out

Charts automatically update whenever values change.

---

## 🧠 Financial Analysis

Automatically generates financial insights including:

* Budget Health
* Savings Rate
* Spending Analysis
* Expense Ratio
* Savings Goal Progress
* Cash Flow Status
* Financial Recommendations

---

## 💾 Local Storage

BudgetFlow Pro automatically saves:

* Budget Inputs

No database is required.

# Installation

1. Clone or download the repository.
2. Ensure the following files are in the same folder:

   * `index.html`
   * `style.css`
   * `script.js`
3. Open `index.html` in your browser.

No server or database is required.
